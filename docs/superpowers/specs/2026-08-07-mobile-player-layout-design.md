# 手机版全屏播放器布局设计

## 目标

- 让封面、歌曲信息、进度、播放控制和辅助操作形成稳定的纵向层级。
- 在 320-430pt 宽、短屏和安全区设备上保持可见、可点击、不溢出。
- 继续支持封面点击进入歌词，并提供明确的歌词按钮作为第二入口。
- 保持当前深色沉浸背景、收藏状态、播放队列、睡眠定时和播放错误处理。
- 只调整手机版全屏播放器，不改变桌面播放器的左右分栏布局。

## 非目标

- 不重写播放器状态管理或音频播放逻辑。
- 不调整歌词解析、队列数据结构或下载功能。
- 不增加新的手势系统；返回手势继续由外层导航处理。

## 页面结构

手机版 `PlayerView` 保持全屏沉浸背景和安全区，内容分为三层：

1. 顶部栏：左侧收起播放器图标，中间显示“正在播放”，不重复显示歌曲名，右侧不再放播放队列入口。
2. 主内容区：封面或歌词视图二选一，区域占据剩余空间并使用稳定的尺寸约束。
3. 底部控制区：歌曲信息、收藏、进度条、主播放控制和三项辅助操作。

歌曲信息显示在封面下方，包含歌曲名、歌手和收藏按钮。歌手沿用现有可点击的 `ArtistNamesLink` 行为。

## 封面状态

- 封面保持正方形、圆角和沉浸背景，不再使用固定的 230pt 最小尺寸。
- 封面尺寸由可用宽度和主内容区高度共同决定：长屏适度放大，短屏优先缩小封面，为播放控制留出空间。
- 封面、歌曲名和歌手作为一个稳定的主内容块，不因按钮状态变化而重新排列。
- 点击封面切换到歌词视图；点击底部歌词按钮执行同一操作。

## 歌词状态

- 歌词只替换主内容区，顶部栏和底部控制区保持位置不变。
- 当前歌词高亮并自动滚动居中，保留点击歌词跳转播放进度。
- 底部辅助区的第一个入口变为“返回封面”，不额外增加顶部返回文字或重复按钮。
- 无歌词、歌词加载中和歌词请求失败继续使用现有状态文案，不遮挡播放控制。

## 控制区

歌曲信息下方依次排列：

- 进度条和已播放/剩余时间。
- 主播放控制：播放模式、上一首、播放/暂停、下一首、循环模式。
- 辅助操作：歌词/返回封面、睡眠定时、播放队列。

每个图标按钮保持至少 46pt 的稳定点击区域，播放/暂停按钮使用更大的圆形主按钮。辅助操作使用固定三列布局，避免歌词状态切换时横向跳动。播放队列只保留底部入口，并继续打开现有底部队列面板。

播放错误横幅放在歌曲信息与进度之间，最多显示两行并提供当前恢复动作。该位置使用固定高度的提示位：无错误时保留相同占位，错误出现或消失时不改变主播放按钮的位置。

## 响应式规则

- 使用 `LayoutBuilder` 根据主内容区的实际高度计算封面尺寸，不依赖固定屏幕高度。
- 适配 320、375、390 和 430pt 宽度，以及 568、667、740 和 844pt 高度。
- 短屏采用更小的封面和间距，但不隐藏播放/暂停、上一首、下一首、进度条或三项辅助入口。
- 所有内容遵守顶部和底部安全区，底部控制不被手势条遮挡。
- 切换封面/歌词时只动画主内容区，控制区保持稳定，避免整页布局跳动。

## 交互与导航

- 收起图标调用当前路由的 `maybePop`，系统返回手势继续由外层导航栈处理。
- 点击收藏沿用 `PlayerController.liked` 和现有登录提示流程。
- 点击歌词、队列、睡眠定时和设备按钮继续调用现有功能入口。
- 当前歌曲变化时恢复封面状态，避免上一首歌曲的歌词视图残留。

## 实现边界

主要修改范围为 `lib/features/player/player_view.dart`：

- `_MobilePlayer`：组织主内容和控制区的固定层级。
- `_MobileDiscStage`：改为基于可用尺寸的封面与歌曲信息布局。
- `_MobileControls`：重排进度、主控制和辅助操作。
- `_TopBar`：移除手机版顶部重复的队列入口。
- `_LyricView`：仅在需要时调整沉浸状态下的边距和可用高度。

桌面分支 `_CoverAndControls`、桌面歌词和桌面队列不在本次范围内。

## 验证方案

- Widget 测试覆盖 320/375/390/430pt 宽度和短屏高度，断言无布局异常。
- 测试封面点击进入歌词、底部歌词按钮进入歌词、返回封面按钮恢复封面。
- 测试播放暂停、上一首、下一首、收藏、睡眠定时和队列按钮仍可找到并响应。
- 测试当前歌曲变化后视图回到封面状态。
- 运行完整 `test/widget_test.dart`、涉及文件的 `flutter analyze` 和格式检查。

## 验收标准

- 手机上首次打开全屏播放器时，封面、歌曲信息、进度和播放控制完整可见。
- 任何支持的手机尺寸下没有底部控制被裁切、横向溢出或按钮位置跳动。
- 用户可以通过封面或底部歌词按钮进入歌词，并通过同一位置返回封面。
- 播放队列只有一个清晰入口，顶部不再与底部重复。
- 桌面播放器行为和布局保持不变。
