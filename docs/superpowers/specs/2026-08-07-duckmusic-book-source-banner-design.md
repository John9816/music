# DuckMusic 小说自定义书源横幅设计

## 目标

在 DuckMusic 小说阅读首页顶部增加清晰可见的自定义书源入口，让用户可以直接浏览 YckCeo 书源目录，并快速进入现有 Legado 书源导入管理面板。

## 现状

DuckMusic 已支持登录用户导入 Legado 书源 JSON、启停和删除书源，并能在搜索模式选择可用的自定义书源。现有入口仅位于标题栏右上角的“书源管理”图标，用户不容易发现；发现页和搜索页也没有说明从哪里获取可导入的书源。

## 交互设计

横幅位于小说页 AppBar 下方、发现/搜索分段控件上方，在发现和搜索两种模式中始终可见。横幅使用当前主题的表面色和强调色，不使用营销式大卡片，保持小说工具页紧凑。

横幅内容包括：

- 书源图标和标题“自定义书源”
- 简短说明“浏览 Legado 书源目录，复制 JSON 后导入”
- “浏览书源库”操作，带外链图标
- “导入书源”操作，带导入图标

桌面和平板使用单行布局；窄屏自动换行，说明文字和两个操作不能溢出或挤压。整个横幅保持固定的最小高度，加载状态或系统字体变化不能推动主要内容产生明显跳动。

“浏览书源库”通过 `url_launcher` 使用外部应用模式打开：

```text
https://www.yckceo.com/yuedu/shuyuan/index.html
```

打不开时显示 SnackBar“无法打开书源目录，请稍后重试”，不静默失败。“导入书源”直接调用现有 `_showSourceManager`，复用 JSON 输入、导入、启停和删除逻辑。标题栏现有“书源管理”图标继续保留，兼顾熟悉原入口的用户。

## 组件边界

在 `book_sources_view.dart` 内新增私有 `_BookSourceBanner` 组件。组件只负责布局与触发两个回调，不直接依赖 API：

- `onBrowse`：打开外部书源目录
- `onImport`：打开书源管理面板

页面 State 负责外链调用和错误反馈，现有 `_showSourceManager` 不改接口。该边界允许 Widget 测试使用回调替身，不需要真实网络或浏览器。

## 错误与安全

- 外链地址固定在客户端代码中，不接受远程或用户输入 URL。
- 使用 `LaunchMode.externalApplication`，不在应用内 WebView 执行第三方页面脚本。
- 外链启动失败或插件抛错时只显示统一提示，不影响小说发现、搜索和阅读。
- 横幅不自动下载、解析或导入目录内容；用户仍需明确复制并提交 Legado JSON。
- 现有后端对 `@js`、Java 和 Packages 等不支持规则的判定继续生效。

## 测试与验收

Widget 测试覆盖：

- 小说页顶部显示“自定义书源”“浏览书源库”“导入书源”。
- 点击“导入书源”打开现有管理面板并显示 JSON 输入框。
- `_BookSourceBanner` 的两个操作分别触发正确回调。
- 320 像素窄屏和桌面宽度下无溢出异常。

外链调用封装为可替换回调，测试不启动系统浏览器。真机验收覆盖 Android、iOS、macOS 和 Windows：点击“浏览书源库”进入系统浏览器并打开指定 URL，返回 DuckMusic 后可立即点击“导入书源”粘贴 JSON。

## 非目标

- 不自动抓取或批量导入 YckCeo 页面中的书源。
- 不改变现有书源 JSON 兼容范围或后端解析规则。
- 不移除标题栏书源管理入口。
- 不在本次改动中重构小说发现、搜索、书架或阅读器页面。
