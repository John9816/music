# 截图播放器调整计划

目标：以用户 2026-11-08 新提供的四张视频截图为验收依据，覆盖此前浅色 Lotus 假设。

约束：最多两个任务；主任务改 Flutter 页面，子任务独立实现 Android 真实 FFT 桥接；保持现有播放、逐字歌词、源和账户行为；本轮开发版验证，不发布正式版。视频叠加播放按钮不是应用控件。

- [x] 播放页：封面模糊提色背景、左对齐标题/歌手、右侧更多、波浪进度、实心圆形播放按钮、底部歌词/歌单/队列/设置。先修改交互测试证明当前界面不符，再调整页面。
- [x] 歌词页：依用户后续反馈移除雨点，保留封面模糊背景、居中歌词、左上退出和右上封面返回；修正高亮层与底层文字的居中宽度；保留逐字时间与字体设置；切换、滚动、返回不误触。
- [x] 睡眠弹窗：居中磨砂卡片，5/15/30/45/60 分钟、本曲结束、自定义，单独测试计时/结束事件。
- [x] 频谱页：依用户后续反馈显示随播放同步的当前歌词和下一句，纯黑底、渐变歌词、小型播放控件、底部真实 FFT 频谱和可拖动进度。仅显式启用才请求 Android 音频可视化权限；不可用显示真实状态；退出/暂停/后台释放。
- [x] 修复浅色播放队列/歌单/更多/音质弹层的主题隔离，保证标题、歌手、选中态及按钮可读。
- [x] 全量测试、静态分析、Android 构建安装、四页截图与模拟器交互验证。记录与截图一致之处和无法从静态图核实的动效。
