# 截图播放器调整记录

日期：2026-11-08。参考：用户四张截图，后补视频 `https://www.youtube.com/watch?v=9q1yhqX2DD4`；最多 root 加一个子任务。

## 已实现

- 播放页：封面模糊颜色背景、顶部收起/喜欢、方形圆角封面、左对齐歌曲/歌手、右侧更多、波浪进度、三枚播放控件、底部歌词/添加歌单/队列/设置。音质按实际业务标签，不伪造截图里的 OPUS 码率。
- 歌词页：依用户后续反馈移除雨滴，使用封面模糊背景、居中歌词、左上返回、右上封面返回；隐藏常驻进度和播放控件；保留歌词点击寻址、逐字时间、滚动恢复跟随及自定义字体。逐字高亮与底层文字统一布局宽度，修复短句居中时高亮偏左、重影。
- 睡眠定时：居中磨砂对话框，5/15/30/45/60 分钟、实际曲目结束暂停、1–1440 分钟自定义。曲末暂停不切下一曲，用户后续seek仍保留位置，新定时不被旧回调覆盖。
- 频谱：依用户后续反馈将曲名/歌手替换为随播放同步的当前歌词和下一句；渐变当前句保留逐字时间、字体设置和前后拖动同步。黑底、简洁控制、白色进度滑块、底部实际 Android Visualizer FFT。32频带镜像展示64柱，约25Hz；拒绝全局session0；只在显式点击启用后请求系统音频可视化权限；无麦克风录制/音频落盘。暂停、后台和页面退出释放。不可用返回真实说明。
- 桌面播放器保留原布局；公共进度条默认仍使用原轨道。
- 队列、歌单、歌曲操作和音质弹层从根 Navigator 取得应用主题，避免播放器白色文字泄漏到浅色背景。队列选中歌曲使用正文色及字重区分，歌手用可读的次级文字色；浅/深主题与淡色强调色均测对比度。
- 后续用户明确要求收藏永远红色：统一 `AppBrand.favoriteRed = #FF3B30`，已收藏爱心、歌单收藏书签及收藏入口使用固定红色，不跟随主题或封面。对应123项界面/交互测试与静态检查通过。
- 频谱服务每次启动重新绑定原生事件监听，先等待旧监听取消，修复 Activity 重建但 Flutter engine 保留时失去频谱数据；处理原生监听缺席和过期回调。
