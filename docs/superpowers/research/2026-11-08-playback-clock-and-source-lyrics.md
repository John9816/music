# 播放时间修复与绿源、橙源逐字歌词

日期：2026-11-08。Flutter 版本仍为 `1.1.48+59`。本地 debug APK 已安装到 `emulator-5554`，应用包 `com.music.player.debug`。本次没有发布 Android 安装包，也没有部署后端到 ECS。

## 播放时间根因及修复

1. 旧代码分别截断已播放毫秒与剩余毫秒。总长 4:00、位置 1:59.9 时会显示 `01:59 / -02:00`，两者少了 1 秒。新增 `PlaybackTime`，两个标签共享同一整秒时间线，改为 `01:59 / -02:01`；未知总长显示 `--:--`，越界位置被约束。
2. 旧 `_guardPosition` 在原生位置后退时按墙钟时间推算进度，缓冲或持续归零时会显示没有真正播放的时间。改为恢复播放时最多 250 ms 保持上次观测值，不额外推算；缓冲、暂停跳转、持续重置跟随播放器真实位置。
3. 跳转完成后原先发送请求位置，例如请求 30 秒、实际落在 29.98 秒，暂停 UI 会停在 30 秒。现在重新读取实际原生位置。

移动播放器、桌面播放器及桌面迷你播放器使用同一时间格式化逻辑；逐字歌词继续使用真实播放位置。
