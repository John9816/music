## 更新兼容与运行验证边界

- 现有 1.1.53 的更新器优先读 ECS，并按运行中的 Android ABI 选包；三种拆分包的 versionCode 分别从 `1064→1065`、`2064→2065`、`4064→4065` 递增，通用包为 `64→65`。
- 已实际观察到正式版 `1.1.53/2064` 检测出 `1.1.54`，应用内下载进度达到 45%。随后正式包在 `23:00:05` 被用户卸载，覆盖安装流程中断。因此本轮没有确认覆盖安装成功、账号保留或其他用户数据保留，也没有据此宣称正式包运行回归通过。
- 新客户端 GitHub 选包改为优先精确匹配 Android ABI，排除已识别的不兼容架构，再使用 universal 或未标架构包兜底；macOS、Windows 原有评分不变。
- 已安装的 1.1.53 客户端仍保留旧 GitHub 选包规则：当 ECS 不可用而回退 GitHub 时，会优先下载 versionCode 65 的 universal 包，无法覆盖 versionCode 1064/2064/4064 的旧拆分包。新客户端源码无法追溯修改旧安装，此类用户应经正常 ECS 通道或选择对应 ABI 的正式包升级。
- 本轮线上收尾没有操作模拟器或 adb；发布后的 UI 调整由主任务单独处理。
