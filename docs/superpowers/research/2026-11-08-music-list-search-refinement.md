# 歌曲列表、搜索与播放器细节调整

## 已实现

- 手机歌曲行统一封面、两行标题/歌手、红色收藏和竖向更多操作；列表收藏按账号共享状态，避免每行重复请求。账号切换和同会话凭据刷新均隔离旧状态。
- 搜索采用单一懒加载滚动视图，接近底部自动追加下一批；请求失败保留已有结果并提供重试，切换查询、类型或音源隔离旧响应。搜索音源继续独立于首页/发现。
- 顶部合并搜索框与音源选择，取消重复标题和上一页/下一页按钮；保留大字体、键盘与读屏操作。
- 播放模式统一为用户指定的列表循环、单曲循环、随机播放，一个按钮切换，原生循环和随机状态互斥。
- 合作歌手选择使用完整应用主题，修复歌曲页进入后浅色背景文字不可见；选择歌手仍进入资料页。
- 播放器的“歌曲操作”只保留下载。列表、队列、歌单管理仍保留各自需要的上下文操作。
- 会员页隐藏兑换入口、弹窗和相关引导，保留会员状态与失败重试。

## 验证证据

- 定向测试与离线视觉夹具：104 项通过。
- 新收藏回归先复现同会话 token 刷新后的播放器爱心不同步，再修复通过；验证旧账号请求不能更新新账号播放器。
- 搜索专项：27 项通过，覆盖连续追加、重试、源隔离和综合结果稳定排列。
- 实际渲染图位于 `build/qa/music-refinement-2026-11-08/screenshots/`，已查看浅深主题搜索、歌手选择、歌单、个人页和播放器，涵盖小屏、大字和横屏。
- 汇总预览：`build/qa/music-refinement-2026-11-08/music-refinement-preview.png`。
- 所有页面渲染使用离线测试数据和占位封面。未操作用户正在使用的模拟器，没有据此宣称真机覆盖升级已验证。

最终全量 Flutter 测试 622 项通过，静态分析无问题；Android 原生测试 9 项通过。会员会话回归 10 项通过，覆盖旧请求成功/失败、登出、同会话 token 刷新和同 token 新会话。正式发布结果另见 Android 发布记录。
