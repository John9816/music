# 逐字歌词接入与验证

日期：2026-11-08。继续用户确认的沉浸歌词方向，补齐实际逐字点亮。版本保持 `1.1.48+59`，安装包为本地 `com.music.player.debug`，未发布。

## 数据核查

此前只检查了 Flutter 客户端读取的 `lineLyrics`，对后端能力判断不完整。检查后端 DTO、音源适配代码及已登录接口实测后确认，`/api/v1/music/lyric` 已提供 `karaokeLyrics`。

- 红源《孤勇者》（1901371647）返回 57 行 YRC、558 个字词时间片，生产解析器全部成功解析。
- 红源同名 Live 版本也返回逐字字段。
- 本次抽查的绿源和橙源同名歌曲只返回普通歌词；不将抽样结果推广为所有歌曲均不支持。

## 实现

- API 优先使用可解析的逐字歌词；缺失、格式不支持或无有效时间片时保留普通 LRC。
- `LrcLine` 增加字词片段。YRC 按绝对毫秒解析开始时间和持续时长，保留空格；忽略元数据及无效、倒序时间行。
- 当前行以同一排版绘制灰色底字，再按每个字词的时间裁切白色前景；使用文本实际选区支持换行，保留整句语义和点击跳转。
- 仅当前逐字行随播放时间重绘；歌词列表仍按当前行变化刷新。
- 小幅向前的播放时间更新采用 80 毫秒过渡，不预测超过播放器报告的时间。暂停、回拖、较大跳转和减少动态效果立即更新。
- 手动浏览、高对比度和辅助导航模式继续采用清晰文本。
