# Android 1.1.56 本地构建与 ECS 发布

日期：2026-11-09，Asia/Shanghai。

## 版本与内容

- 正式版 `1.1.56+67`，源提交 `f408fd6697ef76d3e20235e8fc583eb0705f1352`，已推送至 `flutter-migration`。
- Android ID 保持 `com.music.player`，沿用历史正式签名。4 个 APK 在本机构建；GitHub 仅镜像相同文件，不运行编译或重新签名。
- 更新安装前及安装授权返回后校验包名、签名集合和递增 versionCode；开发包加上“开发版”名称并阻止进入正式更新通道；关于页显示原生版本和渠道。
- 设置移除主题色、液态玻璃质量、减弱动态效果和普通通知，保留媒体通知。修复旧偏好导致动画关闭，以及导航下没有内容导致玻璃模糊不明显的问题；补齐滑动选中层、按压反馈和切页动画。
- 增加直装车机界面和 Android Auto 媒体目录、搜索/语音、播放控制；复用原有播放器及会话，支持账号恢复、目录分页和循环/随机映射。
- 实际完成标准 Android 媒体会话兼容。vivo、OPPO、荣耀等厂商专有岛能力没有完成准入或真机验收；详细范围见 `2026-11-09-android-update-car-media.md`。
- 本次仅发布 Android；未发布桌面端、iOS、网站或后端。网页安装器从同一 ECS 清单自动取得新版信息。
