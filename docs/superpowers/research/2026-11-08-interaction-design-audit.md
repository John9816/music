# Android 整体视觉与交互检查 — 2026-11-08

本轮按用户“整个设计缺少高级感”的补充要求，调整实际界面中的视觉层级、色彩和控件权重，并完成已复现交互问题的修复。调试 APK 已安装到 Android 模拟器；本轮未发布生产版本。

## 视觉调整

- 首页主推改为真实封面主导的卡片，白色播放键独立呈现；渐层保证封面较亮时文字仍可读，大字时卡片允许增长。
- 浅色采用中性灰白背景，深色采用分层深灰；统一根页面标题、区块标题、留白与操作图标对齐。
- 搜索减少大面积彩色块，收拢热搜、搜索源和类型选择的层级；搜索源隔离保持原有逻辑。
- 资料库、个人页和设置减少高饱和彩色功能底块；底栏降低文字与图标的视觉重量。
- 播放器突出封面与白色主播放键，使用正确的上一首/下一首图标，弱化次要操作；迷你播放器调整封面和控件比例。

## 已确认并修复的交互问题

| 问题 | 最终行为与验证 |
| --- | --- |
| 快速点击反馈来不及显示 | 已接受的点击保留 80ms 反馈；取消不执行操作，卸载时释放计时器。保留原生手势竞争延迟。 |
| 列表整行缩放、禁用态不明显、触摸后焦点框 | 列表不整体缩放，禁用控件有明确区别，仅键盘导航模式显示焦点描边。 |
| 窄屏大字标题与按钮挤压 | 标题操作可换行；手机资料库和个人页的紧凑图标正常字号时与标题居中。 |
| 转场监听器未释放 | 播放器、歌曲菜单、应用路由和列表入场动画调整曲线生命周期。 |
| 音量按下后取消仍改变音量 | 完成点击后提交，取消不修改；宽屏迷你播放器触控区扩至 44。 |
| 旧音质弹层可能重试后来切换的歌曲 | 提交前校验歌曲与来源，防止操作替换后的歌曲。 |
| 音质和定时弹层在小屏横屏大字溢出 | 内容可滚动，320×640 / 844×390、2 倍字体有回归覆盖。 |
| 部分弹层忽略减弱动态效果 | 锚点菜单、底部菜单、播放器与设置定时器弹层遵循设置。 |
| 收藏/添加歌单重复请求和失败后状态残留 | 加入请求保护、目标状态捕获与失败恢复；用模拟服务验证，不改真实收藏。 |
| 睡眠定时器到期不暂停 | 清理定时器前捕获回调，到期只调用一次；取消与重置有回归。 |

## 检查范围与限制

本轮验证了视觉和已确认的交互缺陷，不将“高级感”或性能提升作为客观测量结论。未进行真机帧时间基准、长时间后台播放、不同厂商系统和低端设备压力测试。

未执行真实收藏修改、歌单删除、清空历史或账户变更。用户歌单会话切换、批量操作失败反馈、存储加载失败仍有静态疑点，尚未实测确认；不能据本次检查宣称所有异常路径已无问题。嵌套歌曲/歌手/更多控件的全部组合也未逐一真机验证。
