## Implemented

Personal Qishui roaming uses authenticated server sessions, server sequences, retry deduplication, bounded queues, prefetch, and manual queue/account cancellation. Forty-six live modes were returned for the user's already bound account. Start/next each returned twenty songs; replaying the same sequence returned the same page. Closed the smoke-test session afterward.

Five player skins (classic, poster, mist, light, fireworks), persistent appearance settings, bounded artwork background decoding, motion suspended while paused/offscreen/background/reduced-motion. Existing karaoke and full lyric interactions retained. No lyric rain or song-page volume slider. Favorites remain red.

Android EQ is inserted into just_audio's real audio pipeline. Presets/custom bands/bypass persist. Gain requests are normalized to avoid positive band boosts. The pinned just_audio 0.9.46 Android transport divides millibels by 1000 instead of 100; the adapter corrects the unit scale in both directions. An emulator native AudioFlinger dump confirmed an enabled Equalizer in this app's audio session. Native band count is hardware-dependent (five on this emulator); other platforms display unsupported status.

Three mobile tabs with glass refraction and background capture, square mini artwork plus title/artist, search source segments and scopes/history/suggestion cards, centered library heading, six rows and two-column playlists. Local files import by copy with streamed content deduplication. Cloud actions are not offered for local audio.

## Folia and automatic music scan follow-up

Folia revision `5bdade1102f9b80830eec5f523e87f3e2a13d40d` is built locally from
184 upstream modules and pinned npm dependencies. Complete client source is now
AGPL-3.0; AnimCJK stroke data retains APL and bundled dependency notices. The app's
About page links to the version-specific ECS source archive. Publication must
upload and hash-check that source archive before activating the update manifest.

Native audio is the clock authority. Rendering receives no account token or audio
URL; it interpolates a native sample for at most 250 ms, pauses offscreen and in
the background, and redraws paused seeks. Local canvas drawing is capped at
30 fps. Font size and weight are forwarded. Nebbia suppresses droplets and ink
trails, bounds its minimum stroke width for small mobile CJK glyphs, and allocates
optional textures before first use to avoid incomplete-sampler warnings.
