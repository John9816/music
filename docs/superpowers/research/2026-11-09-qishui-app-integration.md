# 黑源 App 接入

日期：2026-11-09，Asia/Shanghai。Android 目标版本：1.1.57+68。

## 范围

依据后端 `docs/tunefree-next-qishui-api.md` 接入 `qishui`（别名 `qs`）。搜索独立提供黑源，只请求歌曲和歌单；首页/发现保持原浏览源，因为黑源不提供已验证的推荐、榜单或分类目录。

歌单不透明复合 ID 和长歌曲/歌手 ID 保留字符串；黑源歌单每页100首，滚动追加、去重、失败重试。歌曲歌手入口支持黑源歌曲目录；歌词沿用 YRC 优先和原始歌曲身份。音质使用上游声明的128K、320K、FLAC、Hi-Res，默认320K，不推断已获得播放权限。

设置和搜索可打开黑源账号页：读取状态、获取 PNG 二维码、抖音深链、每2秒轮询、刷新授权、解绑。退出页面停止轮询，后台暂停，前台恢复；过期、拒绝和连续失败停止。扫码会话只保存在内存；网站会话变更丢弃迟到结果，账号操作不自动重放到新登录会话。解绑确认也核对网站登录代次。

## 明确限制

用户确认没有独立解析凭据。依指定接口文档，抖音扫码获得的个人access_code/ticket与TuneFree v1播放Bearer不是同一授权，不能互换。当前ECS未配置独立解析凭据，黑源播放仍返回1003；本次没有宣称扫码即可完整播放，也没有使用本机第三方账号凭据。CENC加密音频沿用后端明确拒绝。

未由账号持有人完成本轮扫码确认、真实换票或刷新；未操作用户模拟器，不宣称真实覆盖安装或车机验收。未增加未支持的歌单分享短链导入、榜单或专辑搜索。本次发布Android及必要后端修复，不发布桌面或iOS。
