# DuckMusic Android 1.1.48 发布与通知闪退修复

## 范围与根因

用户已明确授权发布安卓版。1.1.47 发布后的覆盖升级验收发现通知图标资源被裁剪，
继续完成发布修复，使用新版本 1.1.48+59，不改写已发布标签。

1.1.46 在模拟器上出现主线程 `IllegalArgumentException: Invalid notification
(no valid small icon)`，时间 2026-11-07 19:38:36（上海），系统退出原因是 APP CRASH。
1.1.47 播放/暂停也记录相同通知异常，并于 19:49:56 点击首页主推切换到不同封面的歌曲时
复现完全相同的主线程崩溃（PID 31808，ApplicationExitInfo reason=4）。
两个正式 APK 的资源表都缺少通知图标，
而 debug APK 中 8 个图标完整。

`audio_service` 通过 Dart 字符串配置通知图标，Android 端使用 `getIdentifier` 动态查找；
Flutter release 启用了资源裁剪。修复在 `res/raw/keep.xml` 保留自定义通知图标与
`audio_service_*` 控件图标，保持资源裁剪和正式签名机制。

`scripts/verify_android_media_resources.py` 检查 APK 资源表中的 8 个图标及实际 ZIP 文件，
已在 1.1.47 正式包上观察到预期失败、在 debug 包上通过。发布流程对四个 APK 都调用该检查。
