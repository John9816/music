## 参考对象修正

用户先给出 `Varun7009/Obsidian-Music`，随后用视频截图明确了带 LOTUS 标题的播放器。两者为不同项目。此次后续设计方向以用户的视频截图和 `dn0ne/lotus` 为准，不将 Obsidian 的深色全屏模糊设计当成视频原型。

- Lotus 源码快照：`00df5cc9ae6d1a72bc4e951d9d7452720f85a442`。
- 参考目录：`build/qa/lotus-reference-2026-11-08/`。
- 官方播放器截图：`fastlane/metadata/android/en-US/images/phoneScreenshots/2.png`（深色状态，与视频相同的结构）。
- 视频是浅色状态：低饱和浅灰背景、顶部辅助工具、居中方形封面和歌名、波浪进度条、三个简洁播放控件。
- 官方源码公开且完整，本轮按源码核对，不需要反编译。Obsidian 的已安装运行时尚未进行完整交互验证；不能把官方截图推测当作实测动效。

## 对照结果

| 项目 | Lotus 源码证据 | DuckMusic 下一轮可借鉴方向 |
| --- | --- | --- |
| 页面层级 | `PlayerSheet.kt` 竖屏使用主题 surface，工具栏置顶，内容整体居中，水平边距 28dp | 播放器跟随浅/深主题，减少当前整页模糊与固定白色控件造成的厚重感 |
| 封面和文字 | 封面占内容宽度，封面下间距 28dp，歌名与歌手居中，切歌文本淡入淡出 | 统一封面、文字与进度的中心轴和间距，避免封面上下留白失衡 |
| 进度条 | `WavingSeekBar.kt` 用位置/时长计算真实进度；余弦曲线周期动画与音频频谱无关，拖动独立保存当前值 | 可以独立实现轻量波浪轨道；必须保留准确拖动、已播/剩余时间与减少动画支持 |
| 控件分组 | 顶部收起、睡眠、队列、歌词、循环和更多；底部只保留上一首、播放/暂停、下一首 | 收起底部过密辅助按钮，音量继续不放在歌曲页 |
| 歌词入口 | 顶部歌词按钮展开独立 `LyricsSheet`，有明确返回 | 比较独立歌词层与现有横滑切换，确保返回路径、拖动进度和歌词滚动互不抢手势 |
| 色彩 | README 明确 Material You 与动态颜色；使用主题语义颜色 | 优先保证浅色对比与层级，封面提色只作为适量强调 |

以上为源码与截图观察和设计建议，未测量视频的实际动画曲线/时长，也未对 DuckMusic 做界面修改。此次已发布的 `1.1.53+64` 是可靠性修复版，不包含 Lotus 风格重做。
